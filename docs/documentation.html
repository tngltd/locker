Developer Guide

This guide explains how to build the Debian package for locker.

Building the Package

The package can be built on both Mac and Linux using Docker.

Prerequisites

  • Docker installed and running
  • Git (to clone the repository)

Build Steps

1. Build the Package

./scripts/build-with-docker.sh

This will:

  • Build a Docker image with Ubuntu and Debian build tools (first time only)
  • Run the build inside a Docker container
  • Output locker_1.0.0-1_all.deb in your project directory

2. Test the Build (Optional)

./scripts/test-docker-build.sh

This will:

  • Build the package
  • Test installation in an Ubuntu container
  • Verify all files are installed correctly
  • Test the CLI

Package Structure

The Debian package includes:

  • /usr/bin/locker - Service daemon entry point (installed by Python package)
  • /usr/bin/locker - CLI management tool entry point (installed by Python package)
  • /usr/lib/python3/dist-packages/lock_service/ - Python package source code
  • /etc/locker/config.json - Configuration file
  • /etc/systemd/system/locker.service - Systemd service file
  • /usr/share/locker/ - Scripts and documentation

Dependencies

The package automatically installs:

  • python3
  • python3-daemon
  • python3-psutil
  • python3-pyudev
  • systemd
  • iptables

Local Development

For local development, install the package in development mode:

# From project root
pip install -e .

# Then use the commands directly
locker --help
locker --help

User Guide

This guide explains how to install and configure locker on your Ubuntu system.

Installation

1. Install the Package

sudo apt install -y ./locker_1.0.0-1_all.deb

Or if the package is in a different location:

sudo mv locker_1.0.0-1_all.deb /tmp/
sudo apt install -y /tmp/locker_1.0.0-1_all.deb

2. Verify Installation

# Check if package is installed
dpkg -l | grep locker

# Test the CLI
locker --help

Configuration

After installation, the service starts in permissive mode, which means it won't lock the system even if the device is disconnected.

Step 1: Get Android Device Serial

Connect your Android device via USB and get its serial number:

locker get-android-serial

This will show all connected Android devices with their serial numbers.

Step 2: Configure Android Serial

Set the Android device serial that will control the lock:

# Option 1: Select from connected devices
locker set-android-serial

# Option 2: Set serial directly
locker set-android-serial ABC123XYZ

Step 3: Add Services to Control

Configure which services should be managed (started on connection, stopped on disconnection):

# Add services to be managed
locker add-service ssh
locker add-service nginx
locker add-service mysql

Step 4: Switch to Enforcing Mode

Once configuration is complete, switch to enforcing mode. Warning: In enforcing mode, the system will lock if the configured Android device is not connected.

locker set-mode enforcing
Important: Make sure your Android device is connected before switching to enforcing mode, otherwise the system will lock immediately.

Modes

Permissive Mode

  • System will not lock even if device is disconnected
  • Safe for configuration and testing
  • Default mode after installation

Enforcing Mode

  • System will lock when configured Android device is disconnected
  • Configured services will be stopped when locked
  • System will unlock when device is connected
  • Requires Android serial to be configured

Service Management

Use systemctl to manage the locker:

# Start the service
sudo systemctl start locker

# Stop the service
sudo systemctl stop locker

# Check status
sudo systemctl status locker

# View logs
sudo journalctl -u locker -f

CLI Commands

Command Description
locker get-android-serial Get serial numbers of connected Android devices
locker set-android-serial [serial] Configure Android device serial
locker list-devices List all connected Android devices
locker add-service <service> Add service to be managed (started on connection, stopped on disconnection)
locker set-mode [permissive|enforcing] Set mode (permissive or enforcing)
locker logs [-n N] Show service logs (last N lines, default 50)

Configuration File

The configuration is stored in /etc/locker/config.json:

{
  "service": {
    "log_level": "INFO",
    "log_file": "/var/log/locker.log"
  },
  "monitoring": {
    "check_interval_seconds": 5
  },
  "mode": "permissive",
  "android_serial": "ABC123XYZ",
  "services": ["ssh", "nginx"]
}

Uninstallation

sudo apt remove locker

This will remove the package but keep configuration files in /etc/locker/.

Troubleshooting

Service Not Starting

# Check service status
sudo systemctl status locker

# View logs
sudo journalctl -u locker -n 50

Device Not Detected

  • Ensure USB debugging is enabled on Android device
  • Check ADB is installed: which adb
  • Test connection: adb devices

Switch Back to Permissive Mode

If you're locked out, you can switch back to permissive mode by editing the config file directly (requires physical access):

sudo nano /etc/locker/config.json
# Change "mode": "enforcing" to "mode": "permissive"
sudo systemctl restart locker
